# tianyi-acu

基于《神針心傳 · 天乙神針續篇》(張偉傑編著，元氣齋出版社) 的择时开穴工具。

## 算法核心
4 大算法来自原书 124-176 页 "奇门通玄针法" 章节:
- **值符** (天干定值日经; 五输穴轮值; 阴阳不匹配表里经代值)
- **值使** (12 地支固定对应值使穴)
- **值阳/值阴** (阳日气纳三焦; 阴日血归心包; 每穴轮值 2 时辰)
- **吉凶时** (12 神煞 + 黄黑道 + 截空 + 五不遇)

## 技术栈
- Python 3 计算核心 (无 pandas, 标准库 only)
- PHP API 包装 (调 Python)
- 纯前端 HTML/CSS/JS (暗金朱砂墨色东方美学)

## 数据
所有数据来自原书 124-176 页结构化整理:
- 60 甲子主表
- 720 吉凶时明细
- 120 值符全时段
- 12 值使规则
- 24 值阳/值阴
- 16 校勘异常 (原书排印错误处理)
