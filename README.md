## 🧮 计算原理

### 干支基准

- **基准日**：1940-09-18 = 甲子日
- **算法**：`((days_since_base + gan_index) % 60)` → 60 甲子循环

### 五鼠遁（时干起法）

> 甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途

按日干决定子时的天干，然后每 2 小时递进一个天干。

### 4 大算法详解

| 算法 | 规则 | 数据 |
|---|---|---|
| **值符** | 同阴同阳 → 本经值符；阴阳不配 → 表里经代值（表经代里经，或里经代表经）| 120 条 |
| **值使** | 12 地支固定对应 12 个值使穴（五输穴轮值）| 12 条 |
| **值阳** | 阳日气纳三焦经，每穴值 2 时辰（子丑 → 井穴，寅卯 → 荥穴...）| 12 条 |
| **值阴** | 阴日血归心包经，同阳日轮值 | 12 条 |
| **吉凶时** | 12 神煞（金匮/天刑/青龙/司命/天牢/白虎/玉堂/天牢/玄武/勾陈/朱雀/明堂）+ 黄道/黑道 + 截空 + 五不遇 → 综合判断 | 720 条 |

### 表里经代值逻辑

```
阳日 (甲丙戊庚壬) + 阳时 (子寅辰午申戌) → 本经值符 (胆经)
阳日 + 阴时 (丑卯巳未酉亥) → 表里经代值 (肝经)
阴日 (乙丁己辛癸) + 阴时 → 本经值符 (肝经)
阴日 + 阳时 → 表里经代值 (胆经)
```

## 🛠️ 技术栈

- **框架**：Next.js 14 (App Router)
- **语言**：TypeScript 5.4
- **样式**：Tailwind CSS + 自定义 CSS 变量（米白宣纸 + 金褐 + 朱砂 + 玉绿东方美学）
- **数据**：**全部写进源代码**（`src/lib/*.ts`），**不依赖外部 Excel / JSON 文件**

- **部署**：静态导出到 TP 子目录

## 🚀 开发与部署

### 开发

```bash
npm install
npm run dev        # localhost:3000
npm test           # 跑全部 1580 个测试
npm run test:watch # 实时测试
```

### 构建

```bash
npm run build      # 输出 out/
```

构建后自动修复 `/_next/` → `/next/` 路径（GitHub Pages 兼容性）。

### 部署到 TP

```bash
rm -rf /<deploy-path>
mkdir -p /<deploy-path>
cp -r out/. /<deploy-path>/

# 改 basePath: 把 _next/ 改为 /TP/tianyi-acu/next/
python3 -c "
import os
for root, dirs, files in os.walk('out'):
    for f in files:
        if f.endswith(('.html', '.js', '.css', '.json', '.txt')):
            fp = os.path.join(root, f)
            content = open(fp, encoding='utf-8', errors='ignore').read()
            new = content.replace('/next/', '/TP/tianyi-acu/next/')
            if new != content:
                open(fp, 'w', encoding='utf-8').write(new)
"

# 改权限
chown -R apache:nginx /<deploy-path>/
```
